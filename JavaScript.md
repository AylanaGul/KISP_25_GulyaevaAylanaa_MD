# Преобразование типов

JavaScript автоматически приводит типы в зависимости от контекста. Есть три основных преобразования:

Строковое

Происходит, когда нужно строковое представление. Явный вызов: String(value).

```js
String(false); // "false"
String(null);  // "null"
```

Если хотя бы один операнд в + является строкой, второй тоже станет строкой: "моя" + "строка" → "моястрока".

Численное

Происходит в математических операциях и при сравнении разных типов (кроме ===/!==). Явный вызов: Number(value) или унарный +.

Значение Результат
undefined NaN
null 0
true / false 1 / 0
Строка Пробелы обрезаются; пустая → 0, иначе число или NaN

Логическое

Происходит в логическом контексте (if). «Ложные» значения (falsy): 0, "", null, undefined, NaN. Остальные — «правдивые» (truthy), включая любые объекты. Явно: Boolean(value) или !!value.

Важно: null и undefined равны только друг другу при ==, но не равны никаким другим значениям.

# Базовые операторы, математика

Термины

· Операнд — то, к чему применяется оператор.
· Унарный — оператор для одного операнда (например, унарный минус -x).
· Бинарный — оператор для двух операндов (например, a - b).

Математические операторы

· Сложение +
· Вычитание -
· Умножение *
· Деление /
· Взятие остатка %
· Возведение в степень **

% возвращает остаток от деления, а не проценты: 5 % 2 → 1.

** возводит в степень: 2 ** 3 → 8.

Особенности +

· Если оба операнда числа — сложение.
· Если хотя бы один — строка, второй тоже приводится к строке: 2 + "3" → "23".

# Операторы сравнения

Все сравнения возвращают true или false.

Строки

Сравниваются посимвольно в лексикографическом порядке (по Unicode). Регистр важен: "a" > "A" → true.

Разные типы

При >, <, >=, <= и == значения приводятся к числу. Например, true == 1 → true, а "" == 0 → true.

Строгое равенство ===

Сравнивает без приведения типов. Если типы разные — сразу false. === надёжнее, чем ==.

null и undefined

· null == undefined → true (особое правило).
· null === undefined → false (разные типы).
· null >= 0 → true, но null > 0 → false (из-за разного поведения == и >=).
· undefined при математических сравнениях даёт NaN, поэтому всегда false.

Совет: избегайте сравнений с null/undefined, кроме ===.

# Условное ветвление: if, '?'

if

Вычисляет условие, приводит его к логическому типу и выполняет блок, если true.

```js
if (year == 2015) {
  alert("Правильно!");
}
```

else

Выполняется, если условие ложно.

else if

Добавляет альтернативные условия.

```js
if (age < 3) {
  message = "Малыш";
} else if (age < 18) {
  message = "Привет";
} else {
  message = "Здравствуйте";
}
```

Тернарный оператор ?

Единственный оператор с тремя операндами. Синтаксис: условие ? значение1 : значение2.

```js
let access = (age > 18) ? true : false;
```

Если нужно выполнить код, а не присвоить значение, лучше использовать if — тернарник хуже читается в таких случаях.

# Логические операторы

Операторы работают с любыми типами, приводя их к логическому значению для вычислений, но возвращают исходное значение.

|| (ИЛИ)

Возвращает первое «истинное» значение или последнее, если все ложные. Вычисления останавливаются на первом true («короткий цикл»).

```js
let name = "" || "Аноним"; // "Аноним"
```

&& (И)

Возвращает первое «ложное» значение или последнее, если все истинные. Останавливается на первом false.

```js
let result = 1 && 2 && null && 3; // null
```

! (НЕ)

Приводит к логическому типу и возвращает противоположное значение.

```js
!true; // false
!!"строка"; // true (двойное НЕ для приведения к boolean)
```

Приоритет: && выполняется раньше ||.

# Операторы нулевого слияния и присваивания: ??, ??=

?? (нулевое слияние)

Возвращает первый определённый аргумент (не null и не undefined). Если левый определён — возвращает его, иначе — правый.

```js
let user = null ?? "Аноним"; // "Аноним"
let height = 0 ?? 100;       // 0
```

Отличие от ||

· || возвращает первое истинное значение.

# Циклы while и for

while

Проверяет условие перед каждой итерацией.

```js
let i = 0;
while (i < 3) {
  console.log(i);
  i++;
}
```

do…while

Проверяет условие после тела цикла, поэтому тело выполнится минимум один раз.

```js
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 3);
```

for

Классический цикл: инициализация → условие → тело → шаг.

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

break и continue

· break — полностью прерывает цикл.
· continue — пропускает текущую итерацию и переходит к следующей.

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) continue;
  if (i === 7) break;
  console.log(i); // 0,1,2,4,5,6
}
```

Метки

Используются для выхода из вложенных циклов.

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
    console.log(i, j);
  }
}
```

# Конструкция switch

switch сравнивает значение со значениями case через строгое равенство ===.

```js
let x = 2;

switch (x) {
  case 1:
    console.log('один');
    break;
  case 2:
  case 3:
    console.log('два или три');
    break;
  default:
    console.log('другое');
}
```

Важно:

· break обязателен, иначе выполнение «провалится» в следующий case.
· default — необязательный блок, выполняется, если совпадений нет.
· Можно группировать case:

```js
case 2:
case 3:
  console.log('2 или 3');
  break;
```

# Функции

Объявление функции

```js
function sum(a, b) {
  return a + b;
}

let result = sum(2, 3); // 5
```

· Параметры — локальные переменные внутри функции.
· return возвращает значение и завершает функцию.
· Если return нет, функция возвращает undefined.
· Функция может обращаться к внешним переменным, но лучше делать её предсказуемой.

Function Declaration

```js
function greet(name) {
  return 'Привет, ' + name;
}
```

Особенность: всплытие (hoisting) — такую функцию можно вызвать до её объявления.

```js
sayHi(); // работает

function sayHi() {
  console.log('Привет');
}
```

# Function Expression

Функция как значение, присвоенное переменной.

```js
const sum = function(a, b) {
  return a + b;
};

console.log(sum(2, 3)); // 5
```

Особенности:

· Создаётся в момент выполнения кода.
· Не всплывает так, как Function Declaration.
· Может быть анонимной.
· Часто используется как колбэк.

```js
const numbers = [1, 2, 3];
numbers.forEach(function(num) {
  console.log(num);
});
```

Отличие от Function Declaration

```js
// Function Declaration — можно вызвать раньше
foo(); // ok
function foo() {}

// Function Expression — нельзя вызвать раньше
bar(); // ошибка
const bar = function() {};
```

# Стрелочные функции, основы

Короткий синтаксис для функций.

```js
const sum = (a, b) => a + b;
console.log(sum(2, 3)); // 5
```

Если один параметр — скобки можно опустить:

```js
const double = n => n * 2;
```

Если параметров нет — нужны пустые скобки:

```js
const hello = () => 'Привет';
```

Если тело из нескольких строк — нужны {} и return:

```js
const sum = (a, b) => {
  const result = a + b;
  return result;
};
```

Особенности стрелочных функций:

· Нет своего this.
· Нет arguments.
· Нельзя использовать как конструктор (new).
· Удобны для коротких функций и колбэков.

```js
const nums = [1, 2, 3];
const squares = nums.map(n => n * n); // [1, 4, 9]
```

# Особенности JavaScript

· Динамическая типизация — тип переменной определяется значением, и он может меняться.
  ```js
  let x = 5;
  x = 'строка';
  ```
· Слабая типизация — JavaScript часто сам приводит типы.
  ```js
  console.log('5' + 1); // '51'
  console.log('5' - 1); // 4
  ```
· Прототипное наследование — объекты наследуют свойства через прототипы.
· Функции — объекты первого класса — их можно присваивать, передавать, возвращать.
· Асинхронность — event loop, колбэки, промисы, async/await.
· Интерпретируемый язык с JIT-компиляцией — выполняется в браузере и в Node.js.
· Кроссплатформенность — работает в браузерах, на серверах, в мобильных приложениях и т.д.
· Интеграция с HTML/CSS/DOM — основной язык для интерактивных веб-страниц.
· Ограничения безопасности в браузере — например, same-origin policy.
· Есть null, undefined, NaN — нужно аккуратно проверять значения.
· Строгий режим 'use strict' — включает современный режим с более строгими правилами.
