# Преобразование типов
Чаще всего операторы и функции автоматически приводят переданные им значения к нужному типу.
Например, alert автоматически преобразует любое значение к строке. Математические операторы преобразуют значения к числам.
Есть также случаи, когда нам нужно явно преобразовать значение в ожидаемый тип.

Строковое преобразование
Строковое преобразование происходит, когда требуется представление чего-либо в виде строки.

Например, alert(value) преобразует значение к строке.

Также мы можем использовать функцию String(value), чтобы преобразовать значение к строке:

```js
let value = true;
alert(typeof value); // boolean

value = String(value); // теперь value это строка "true"
alert(typeof value); // string
```
Преобразование происходит очевидным образом. false становится "false", null становится "null" и т.п.

Численное преобразование
Численное преобразование происходит в математических функциях и выражениях.

Например, когда операция деления / применяется не к числу:

```
alert( "6" / "2" ); // 3, строки преобразуются в числа
```
Мы можем использовать функцию Number(value), чтобы явно преобразовать value к числу:
```js
let str = "123";
alert(typeof str); // string

let num = Number(str); // становится числом 123

alert(typeof num); // number
```

Явное преобразование часто применяется, когда мы ожидаем получить число из строкового контекста, например из текстовых полей форм.

Если строка не может быть явно приведена к числу, то результатом преобразования будет NaN. Например:
```js
let age = Number("Любая строка вместо числа");

alert(age); // NaN, преобразование не удалось
```

Логическое преобразование
Логическое преобразование самое простое.

Происходит в логических операциях (позже мы познакомимся с условными проверками и подобными конструкциями), но также может быть выполнено явно с помощью функции Boolean(value).

Правило преобразования:

Значения, которые интуитивно «пустые», вроде 0, пустой строки, null, undefined и NaN, становятся false.
Все остальные значения становятся true.
Например:
```js
alert( Boolean(1) ); // true
alert( Boolean(0) ); // false

alert( Boolean("Привет!") ); // true
alert( Boolean("") ); // false
```

Итого
Существует 3 наиболее широко используемых преобразования: строковое, численное и логическое.

Строковое – Происходит, когда нам нужно что-то вывести. Может быть вызвано с помощью String(value). Для примитивных значений работает очевидным образом.

Численное – Происходит в математических операциях. Может быть вызвано с помощью Number(value).

# Базовые операторы, математика
Операнд (аргумент) — то, к чему применяется оператор. В выражении 5 * 2 операндами являются числа 5 и 2.
Унарный оператор — применяется к одному операнду (например, унарный минус: -x).
Бинарный оператор — применяется к двум операндам (например, сложение: y + x).
Математические операторы
+ — сложение
- — вычитание
* — умножение
/ — деление
% — взятие остатка от деления (8 % 3 вернет 2)
** — возведение в степень (2 ** 3 вернет 8, а 4 ** (1/2) вернет 2)
Особенности работы со строками, унарный плюс и инкремент
Бинарный + со строками: Если хотя бы один операнд является строкой, второй преобразуется в строку, а операция выполняет конкатенацию (слева направо). Остальные операторы (-, /, *) всегда преобразуют операнды в числа.
Унарный плюс (+): Преобразует не-числа в числовой формат (аналог Number()), например, +true дает 1, а +"" — 0.
Инкремент (++) и декремент (--): Применяются только к переменным. Различают префиксную форму (сначала меняет значение) и постфиксную (возвращает старое значение до изменения).
Приоритет, присваивание и специальные операторы
Приоритет операторов: Выражения выполняются по таблице приоритетов (унарные операторы имеют более высокий приоритет, чем математические, а скобки задают наивысший порядок).
Присваивание и сокращенная арифметика: Оператор = возвращает присвоенное значение, допускается цепочка присваиваний. Сокращенные записи вроде n += 5 объединяют операцию с присваиванием.
Побитовые операторы и запятая: Побитовые операторы работают с 32-битным двоичным представлением чисел. Оператор «запятая» (,) вычисляет несколько выражений, но возвращает результат последнего.

# Операторы сравнения
1. Результат сравнения имеет логический тип
Все операторы сравнения возвращают логический тип: true или false.
Если типы одинаковые, они сравниваются как обычно (числа по значению, булевы по принципу true > false).

2. Сравнение строк
Строки сравниваются посимвольно по кодам UTF-16:
Сравнение идет слева направо до первого несовпадающего символа.
Строчные буквы имеют код больше, чем заглавные ('a' > 'Z' // true).
Длина строки имеет значение, только если начало строк полностью совпадает ('слон' > 'сло' // true).
```js
'2' > '12'     // true (символ '2' больше символа '1')
'cat' > 'car'   // true ('t' идет после 'r')
```

3. Сравнение разных типов
При использовании == (и операторов >, <, >=, <=) JavaScript приводит операнды к числам:
Строки преобразуются в числа.
Булевые значения: true → 1, false → 0.
```js
'01' == 1       // true  (1 == 1)
true == 1       // true  (1 == 1)
false == ''     // true  (0 == 0)

// Парадокс нестрогого равенства:


let x = '0';
Boolean(x) == true; // true  (непустая строка — это true)
x == true;          // false (строка '0' преобразуется в число 0, а true в 1. 0 != 1)
```

4. Строгое сравнение
Проверяет равенство без приведения типов.
Если типы разные, всегда возвращает false.
Рекомендуется использовать по умолчанию вместо ==.
```js
0 == false      // true
0 === false     // false (number !== boolean)
```

5. Сравнение с null и undefined
При нестрогом равенстве (==)
Эти два значения равны друг другу, но не равны больше ничему в языке.

```js
null == undefined // true
null == 0         // false
undefined == 0    // false
```

6. Странный результат сравнения null и 0
null преобразуется в число 0.
undefined преобразуется в NaN. Любое сравнение с NaN дает false.

```js
// Аномалия с null:
null > 0   // false (0 > 0)
null == 0  // false (по правилу выше, null равен только undefined)
null >= 0  // true  (0 >= 0)

// С undefined всё всегда false:
undefined > 0  // false (NaN > 0)
undefined >= 0 // false (NaN >= 0)
```

# Условное ветвление: if, '?' 
1. Инструкция if, преобразование к логическому типу
Инструкция if(...) вычисляет выражение в скобках и приводит результат к булевому типу (как функция Boolean()).
Что всегда преобразуется в false (Falsy-значения)
Число 0 и 0n (BigInt)
Пустая строка ""
null
undefined
NaN
Любые другие значения (включая строки с пробелами, строки "0", пустые массивы [] и объекты {}) всегда преобразуются в true.
```js
if (0) { ... }       // Никогда не выполнится
if ("0") { ... }     // Выполнится (непустая строка — это true)
if (" ") { ... }     // Выполнится (строка с пробелом — это true)
```

2. Блок "else", Несколько условий: "else if"
Используются для создания цепочки условий. Проверка идет сверху вниз до первого совпадения.
```js
let year = 2026;

if (year < 2026) {
  // Код выполнится, если первое условие истинно
} else if (year > 2026) {
  // Код выполнится, если первое ложно, а это истинно
} else {
  // Код выполнится, если все условия выше ложны
}
```
3. Условный оператор "?"
Единственный оператор в JavaScript, который принимает три операнда. Используется для возврата значения в зависимости от условия, а не для замены полноценного if.
Синтаксис
```js
let результат = (условие) ? значение_если_true : значение_если_false;
```

4. Несколько операторов "?"
Заменяет цепочку else if. Вычисляется последовательно.
```js
let age = 20;

let message = (age < 3) ? 'Здравствуй, малыш!' :
              (age < 18) ? 'Привет!' :
              (age < 100) ? 'Здравствуйте!' :
              'Какой необычный возраст!';
```

5. Нетрадиционное использование "?"
Не используйте тернарный оператор для выполнения действий без присвоения результата. Это делает код нечитаемым.
Плохо:
```
(company == 'Netscape') ? alert('Верно!') : alert('Неверно.');
```
Хорошо:
```js
if (company == 'Netscape') {
  alert('Верно!');
} else {
  alert('Неверно.');
}
```

6. Перепишите 'if' в '?'
Перепишите конструкцию if с использованием условного оператора '?':
```js
let result;

if (a + b < 4) {
  result = 'Мало';
} else {
  result = 'Много';
}
```
7. Перепишите 'if..else' в '?'
Перепишите if..else с использованием нескольких операторов '?'.

Для читаемости рекомендуется разбить код на несколько строк.
```js
let message;

if (login == 'Сотрудник') {
  message = 'Привет';
} else if (login == 'Директор') {
  message = 'Здравствуйте';
} else if (login == '') {
  message = 'Нет логина';
} else {
  message = '';
}
```

# Логические операторы
В JavaScript есть три основных логических оператора: || (ИЛИ), && (И) и ! (НЕ). Хотя их называют «логическими», они могут применяться к значениям любого типа и возвращать также значения любого типа.

Оператор || (ИЛИ)

Синтаксис: result = a || b;
Принцип работы: Вычисляет операнды слева направо. Если находит первое «истинное» значение, возвращает его и останавливается. Если все значения «ложные», возвращает последнее из них. Говорят, что || «запинается на правде».
Короткое замыкание: Если первый аргумент true, остальные не вычисляются. Это важно, если последующие выражения имеют побочные эффекты.
Использование: Часто применяется для выбора первого «истинного» значения из списка или для задания значения по умолчанию.

```js
let userName = prompt("Кто там?") || "Аноним";
// Если пользователь отменил ввод (null), будет "Аноним".
```

Оператор && (И)

Синтаксис: result = a && b;
Принцип работы: Вычисляет операнды слева направо. Если находит первое «ложное» значение, возвращает его и останавливается. Если все значения «истинные», возвращает последнее из них. Говорят, что && «запинается на лжи».
Использование: Может использоваться для проверки нескольких условий или для выполнения действия только при истинности первого операнда.

```js
let hour = 12;
(hour > 10) && alert("Добрый день!");
// alert выполнится, так как первое условие истинно.
```

Оператор ! (НЕ)

· Синтаксис: result = !value;
· Принцип работы: Приводит аргумент к логическому типу (true/false), затем возвращает противоположное значение.
· Двойное НЕ (!!): Используется для явного преобразования значения к логическому типу.

```js
alert( !true ); // false
alert( !!("непустая строка") ); // true
```

Операторы нулевого слияния и присваивания: ??, ??=

Оператор нулевого слияния (??)

Синтаксис: result = a ?? b;
Принцип работы: Возвращает первый аргумент (a), если он не null и не undefined. В противном случае возвращает второй аргумент (b).
Назначение: Используется для задания значения по умолчанию для переменной, которая может быть не определена (null или undefined).

```js
let user;
alert(user ?? "Аноним"); // "Аноним" (так как user = undefined)

user = "Иван";
alert(user ?? "Аноним"); // "Иван" (значение определено)
```

Отличие от ||: Оператор || возвращает первое истинное значение, а ?? — первое определённое. || не различает false, 0 и пустую строку "", считая их ложными, а ?? считает их определёнными.

```js
let height = 0;
alert(height || 100); // 100 (потому что 0 — ложное значение)
alert(height ?? 100); // 0 (потому что 0 — определённое значение, не null/undefined)
```

Приоритет: ?? имеет такой же низкий приоритет, как и || (ниже, чем +, *), но выше, чем = и ?. При смешивании с && или || обязательно использовать скобки, иначе будет синтаксическая ошибка.

# Оператор нулевого присваивания (??=)

Синтаксис: x ??= y;
Принцип работы: Присваивает x значение y только в том случае, если x равно null или undefined. Если x уже определено, присваивание не происходит.
Преимущество: Позволяет сократить громоздкую проверку if (x === null || x === undefined) до одной строки.

```js
let userAge = null;
userAge ??= 18;
alert(userAge); // 18

userAge = 25;
userAge ??= 18;
alert(userAge); // 25 (присваивание не произошло)
```
